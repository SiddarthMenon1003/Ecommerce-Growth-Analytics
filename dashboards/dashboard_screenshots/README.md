# Dashboard screenshots

PNG exports of the Power BI report pages, for the project README and portfolio use.

## How to regenerate

The report is authored in PBIP (text) format, so screenshots are exported by hand from
Power BI Desktop:

1. Open `dashboards/product_growth_analytics_lab.Report` in Power BI Desktop and **Refresh**.
2. For each page, **File → Export → Export to PDF**, or use **Win+Shift+S** to capture the
   canvas at 1600×1050.
3. Save one PNG per page here, named by page, e.g.:
   - `01_overview.png`
   - `02_retention.png`
   - `03_clv.png`
   - `04_segmentation.png`
   - `05_marketing.png`
   - `06_fulfillment.png`
   - `07_revenue_growth.png`
   - `08_churn.png`

Keep the 8-page narrative order so the images read as the same story as the report.
